Why you can trust the screen you're reading

  1. The agent boots in a sealed enclave. It generates its signing key inside Intel TDX. No human — including us — ever sees that key.
  2. Google signs a statement about it. An OIDC attestation token binds the exact container image digest, the hardware, and the enclave's address.
  3. The chain checks that token itself. WardAttestor verifies Google's RS256 signature and the image digest on-chain, then installs the enclave key as the only signer Guardian trusts. Anyone can submit it — no owner privilege.
  4. This page came from that same enclave. The UI is served by the attested agent. The thing you're talking to is the thing that was measured.
